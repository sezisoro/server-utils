# server-utils

Collections of scripts and minor programs that don't deserve their own repos,
revolving around maintenance and automation for a multimedia server.

This is as much tools used daily as practice space for developing a 'house
style' and workflow in programming. Programs will be re-written in multiple
languages for the fun of it, libraries will have superflueous algorithm
alternatives, packages will be over-engineered for the task at hand. What
homelabs are for sysadmins this is for my engineering practice.

At time of writing, these projects will attempt to follow the Google style
guides and use opinionated formatters like python-black & mypy. Eventually a
more custom-built style & tooling will be developed in a parallel repository.
